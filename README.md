
• Build an app that shows a list of transactions on home screen, and each transaction should be
clickable to show the details in a second screen.
• fetch the list of transactions from transaction-list.json 
• Display the list of transactions and show the merchant name/description and amount for each
transaction.
• On clicking any transaction, the user should be shown the transaction details page

• On transaction details page, the user should see a green checkmark and Credit transaction as
title for CREDIT transactions and a red checkmark with Debit transaction title for DEBIT
transactions
• Transaction details has a ToolTip component which will expand/collapse when the user taps
show more/show less
• Clicking the Close button will close the presented details page and navigate the user back to the
Transaction list page.
